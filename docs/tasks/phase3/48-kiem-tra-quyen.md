# 48. Kiểm tra quyền trước khi chạy

- [ ] **48. Kiểm tra quyền** *(người dùng yêu cầu 2026-10-24)* – Tính năng cần quyền hệ điều hành thì có chỗ **xem đã có quyền chưa** (và cấp), không phải chạy mới biết lỗi `permission`.
  - **Chốt 2026-10-24:** (1) **Cài đặt → tab Quyền** là chỗ chính; (2) **cảnh báo trên node** thiếu quyền + **trước khi Chạy** (liệt kê quyền thiếu, không chặn cứng); (3) Automation kiểm tra bằng **hỏi hệ điều hành không bật hộp thoại** (`AEDeterminePermissionToAutomateTarget`, askUser=false) – đích chưa mở thì báo *chưa rõ*; nút *Cấp quyền* mới bật hộp thoại thật; (4) **macOS trước**, Windows chỉ hiện mục tương đương (OCR Tesseract, Chrome của app, chạy Admin khi điều khiển cửa sổ quyền cao), còn lại "không cần".
  - Quyền macOS cần kiểm tra: Accessibility (chuột / phím robotgo, phần tử màn hình, bước 37 / 43 E) · Screen Recording (chụp, tìm ảnh / chữ; đã có `ScreenCaptureAllowed`) · Automation → Google Chrome (tab, PDF; `-1743` ở `browser/parse.go`), Finder (Thùng rác; `device/trash_darwin.go`), System Events (cửa sổ, nguồn, màn hình, bộ gõ) · Thông báo (node `notify`) · Chrome *Allow JavaScript from Apple Events* (nếu node dùng) · Keychain (kho bí mật, lần đầu).
  - [x] P1. **Go**: package `internal/perm` – `Check() []Item{id, name, state: granted|denied|unknown|notNeeded, hint, settingsURL}` qua interface (bản giả cho test); `System` macOS (AX `ax_trusted`, `CGPreflight`, Automation theo bundle id đích, thông báo), `_other` trả rỗng (mục tương đương Windows làm sau, chưa có). Method `App`: `Permissions()`, `RequestPermission(id)`, `OpenPermissionSettings(id)` (URL `x-apple.systempreferences:`)
  - [x] P2. **Ánh xạ node → quyền**: hàm thuần `perm.NeedsOf(step)` / `perm.Needs(script)` (Go, `internal/perm/needs.go` – đặt trong `perm` để `script` không kéo cgo) + bản TS `flow/perms.ts` cùng tên, test chung `testdata/` (mọi loại node trong `flow/nodeInfo.ts` phải khai báo quyền cần hoặc "không" – test đỏ nếu thiếu; cập nhật skill `add-node-type`)
  - [x] P3. **Cài đặt → tab Quyền** (`settings/PermSettings`): danh sách quyền + trạng thái, nút Cấp quyền / Mở System Settings / Kiểm tra lại, tự kiểm tra lại khi cửa sổ lấy lại focus; mục nào đang được kịch bản đang mở dùng thì ghim lên đầu
  - [x] P4. **Cảnh báo**: chấm cảnh báo trên `NodeCard` + dòng trong inspector (nút nhảy sang tab Quyền); bấm Chạy / F8 với kịch bản thiếu quyền → hộp thoại liệt kê, chọn *Vẫn chạy* hoặc *Mở Cài đặt*; AI: `run_script` / `wait_run` / `get_preferences` trả `missingPermissions`, thêm tool `check_permissions` (thanh mini không cần – hộp thoại hiện trước khi thu cửa sổ). Chỉ quyền `denied` tính là thiếu; `unknown` không cảnh báo
  - [x] P5. Mã lỗi `permission` khi chạy kèm `id` quyền thiếu để UI chỉ thẳng tới mục đó
  - Chuẩn bị cho MCP (31): có – `check_permissions` tool (chỉ đọc) để AI biết trước thay vì thử chạy
