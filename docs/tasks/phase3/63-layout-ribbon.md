# 63. Layout chính kiểu ribbon (Word)

- [x] **63. Layout chính kiểu ribbon** *(người dùng yêu cầu 2026-11-16, đã duyệt design `design/mockup-ribbon.html`)* – trên cùng là thanh tiêu đề + ribbon theo tab gom mọi nút; phần dưới chỉ còn canvas để kéo thả; viền resize quanh cửa sổ (hiện ở màn soạn không nắm kéo được).
  - Đã chốt theo mockup (2026-11-16): thư viện kịch bản, Mở gần đây, Mẫu thử, Lịch sử chạy, Thùng rác, Cài đặt chuyển vào **trang Tệp** (backstage toàn cửa sổ) – bỏ thanh bên trái; inspector **nổi** trên canvas, chỉ hiện khi chọn node, ghim được vào cạnh phải; tab *Chèn node* có nút từng loại node theo nhóm; nút Chạy + số vòng cố định bên phải hàng tab; zoom chuyển xuống status bar.
  - [x] R1. Viền resize: `components/shell/EdgeResize.tsx` – 4 cạnh dày 6px + 4 góc 12px `fixed z-[100]` (trên mọi lớp, kể cả canvas / popup / inspector nổi), bấm xuống gửi `resize:<cạnh>-resize` cho Go (cùng lệnh runtime Wails gửi; `startResize` Win32); tắt khi phóng to / toàn màn hình (`WindowIsMaximised` / `WindowIsFullscreen`). **Nguyên nhân:** runtime Wails chỉ bắt mép bằng `mousemove` toàn cửa sổ (so `clientX` với `outerWidth`, 6px) nên bị canvas React Flow (d3-zoom nuốt sự kiện chuột) và popup che, con trỏ resize cũng bị phần tử con ghi đè → vẽ viền riêng thay vì dựa vào đó. macOS: cửa sổ frameless vẫn nhận kéo mép gốc → không vẽ viền ở macOS (chờ thử tay).
  - [x] R2. Thanh tiêu đề mới (`TitleBar.tsx`, chỉ hiển thị): truy cập nhanh (Lưu / Hoàn tác / Làm lại), tên kịch bản giữa + chip Chưa lưu, Hướng dẫn (F1), ⚙ Cài đặt (`Ctrl+,`), nút cửa sổ. Bỏ nút Thử trang + chọn theme khỏi thanh tiêu đề (sang tab Công cụ / Xem). Ô *Tìm lệnh* (Alt+Q) trong mockup chưa làm – ngoài R2.

Khung ribbon: `components/ribbon/` – `RibbonView` (tab + nhóm, nút lớn / nhỏ, nhãn nhóm, nút giãn theo chữ tối đa 2 dòng, cuộn ngang khi hẹp, thu gọn `Ctrl+F1` / bấm đúp tab, hàng tab kéo được cửa sổ), `model.ts` (danh sách lệnh là dữ liệu thuần + `columnsOf`, test `model.test.ts`), `ribbonIcons.tsx`, `runItems.ts`.
