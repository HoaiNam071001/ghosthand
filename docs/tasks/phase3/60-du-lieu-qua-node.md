# 60. Nhìn rõ dữ liệu qua node

- [ ] **60. Dữ liệu qua node** *(người dùng yêu cầu 2026-11-02: muốn thấy rõ input / output của từng node, nối dữ liệu giữa các node dễ thao tác, Lịch sử chạy dạng cây thấy giá trị chạy qua từng node)* – nhìn thẻ là biết node đọc biến gì từ đâu, trả ra gì; kéo output sang input để nối; xem lại lần chạy thấy đúng giá trị đi qua từng node, từng lượt lặp.
  - **Design (người dùng duyệt 2026-11-02, bản 3):** https://claude.ai/artifact/GnFB6LJZXAcg4KWixJR8ne – dữ liệu mẫu *Bảng giá – chọn món rẻ*.
  - **Đã chốt (2026-11-02):**
    - Thẻ node có 2 kiểu, nút đổi trên thanh canvas: **Gọn** (thẻ v3 hiện tại) / **Đầy đủ** (thêm khối VÀO – trường nhận biến, ô vuông mép trái; RA – output, ô vuông mép phải). Chấm tròn = luồng chạy, ô vuông = dữ liệu; dây dữ liệu nét đứt màu `cat-data`, sáng `accent` khi chọn node.
    - Kéo output → input để nối (cả 2 kiểu thẻ). **Chỉ nối tới node chạy sau node nguồn** (theo `flowOrder`); kéo về node chạy trước → node mờ + dòng lý do. Nối / bỏ nối có hoàn tác.
    - Thẻ Gọn: rê chuột ~0.4 s → input toả bên trái, output toả bên phải (node khác mờ); kéo output đi qua node nào thì input của node đó toả ra để thả; ra chỗ trống vẫn giữ input đang toả.
    - Chi tiết node mở kiểu **Panel** (mặc định, như hiện tại) / **Modal** / **Popover** dưới node – một nội dung dùng chung; Modal / Popover đóng khi bấm ra ngoài / Esc.
    - Lịch sử chạy là **cây node từ trên xuống** (không phải danh sách cây): mỗi lần node chạy một thẻ, mỗi lượt lặp một nhánh, gom về *Hết danh sách*. Mặc định **Gọn · rê xem**: rê thẻ mở popover VÀO / RA (giá trị đã thay biến, nguồn, nơi dùng) + vẽ đường dữ liệu của thẻ đó. Kiểu **Luôn hiện**: pill giá trị toả trên / dưới mọi thẻ. Bấm thẻ: đường dữ liệu dẫn tới nó sáng, chạy theo chiều giá trị; bảng chi tiết bên phải có VÀO / RA / đi tiếp / *Truy ngược dữ liệu* / log / ảnh lúc lỗi, bấm nguồn → cây cuộn tới thẻ đó.
  - **Còn hỏi (đề xuất của AI trong ngoặc – chưa chốt, hỏi lại khi làm tới):** độ trễ toả cổng (0.4 s, không cần Cài đặt); thả biến vào trường có giá trị cố định (thay luôn + thông báo hoàn tác); thả vào ô chữ đã có biến (chèn cuối chữ); lần chạy nhiều lượt (hiện 10 nhánh đầu + "N lượt nữa", nhánh lỗi luôn hiện); kiểu thẻ Gọn / Đầy đủ nhớ ở đâu (Cài đặt chung, không ghi vào file kịch bản); bảng Nhật ký 220 px dưới canvas giữ danh sách *Từng bước*, thêm nút mở cây.
