# 54. Đồng bộ kịch bản lên cloud (Google Drive, MCP)

- [ ] **54. Đồng bộ cloud** *(người dùng yêu cầu 2026-10-28: đăng nhập Google rồi đồng bộ kịch bản + ảnh mẫu / tệp đi kèm + cài đặt + kho bí mật lên cloud, có thể qua MCP server khác; xung đột thì hỏi người dùng)*
  - **Đã có để dựa vào:** `store/revision.go` (revision kịch bản), `store/storagedirs.go` (thư mục kịch bản), `internal/secrets` (kho bí mật + keychain), `internal/ai` (mẫu gọi dịch vụ ngoài + key qua `{{secret.*}}`), 31d còn node *Gọi tool MCP* (app làm MCP client) – **dùng chung client MCP** với bước này, không viết hai lần.
  - **Cần chốt khi làm (mặc định đề xuất):** (1) backend đầu tiên = **Google Drive API trực tiếp** (OAuth loopback + PKCE, scope `drive.file` – app chỉ thấy file nó tạo, thư mục `Ghosthand` trong Drive); (2) backend **MCP** là đợt sau vì tên tool mỗi server Drive khác nhau → cần bảng ánh xạ; (3) bí mật **mã hoá phía máy** bằng cụm mật khẩu riêng, cloud chỉ giữ bản mã.
  - **Rủi ro:** đăng ký app Google (màn hình đồng ý OAuth, client ID đi kèm bản phát hành; `drive.file` không cần Google duyệt scope nhạy cảm); quên cụm mật khẩu = mất bí mật trên cloud (không khôi phục); hai máy sửa cùng lúc; ảnh mẫu nhiều → upload chậm (chỉ đẩy file đổi, so hash); token hết hạn giữa chừng.
  - [ ] C0. Khung `internal/cloud`: interface `Provider` (`List`, `Get`, `Put` có `ifMatch`, `Delete`) + bản giả cho test; manifest `manifest.json` trên cloud (đường dẫn tương đối → hash, revision, máy sửa cuối, thời điểm); mô hình phạm vi đồng bộ (kịch bản `.json`, ảnh mẫu / tệp đi kèm, cài đặt, bí mật)
  - [ ] C1. Đăng nhập Google: OAuth loopback + PKCE trong `internal/cloud/gdrive`, mở trình duyệt hệ thống (không webview – tránh chặn đăng nhập); refresh token cất vào keychain (`internal/secrets`), **không** vào `settings.json`; nút Đăng xuất = xoá token + thu hồi
  - [ ] C2. Provider Google Drive: thư mục gốc `Ghosthand` trong Drive, upload resumable cho file lớn, `ifMatch` bằng etag / `headRevisionId`, thử lại có lùi dần khi lỗi mạng / 429
  - [ ] C3. Engine đồng bộ `cloud.Sync`: so ba bên (bản máy – bản cuối đã đồng bộ – bản cloud) theo hash; chỉ đẩy / kéo file đổi; hàm thuần có test cho mọi ô của bảng quyết định (chỉ đổi một bên, đổi hai bên, xoá một bên, mới cả hai)
  - [ ] C4. Xung đột: **hỏi người dùng** – hộp thoại chọn *Giữ bản máy này / Lấy bản cloud / Giữ cả hai (bản cloud lưu thành `tên (máy khác).json`)*, hiện giờ sửa + tên máy hai bên; không bao giờ tự ghi đè; kịch bản đang mở có cờ chưa lưu thì hoãn kéo về
  - [ ] C5. Ảnh mẫu / tệp đi kèm: quét tham chiếu (`imageSource`, tệp trong node Tệp / HTTP…) → đẩy cùng kịch bản; đường dẫn tuyệt đối trên máy này ghi lại dạng tương đối, máy kia kéo về đặt vào thư mục lưu của máy đó (`ScriptsDir`) và viết lại đường dẫn; thiếu file thì báo, không im lặng
  - [ ] C6. Cài đặt: chỉ phần **mang đi được** (theme, ưu tiên node, phím tắt, lịch…); loại phần riêng từng máy (thư mục lưu, cổng API, token, kết quả kiểm tra quyền) – danh sách trắng trong `store`, thêm trường cài đặt mới phải chọn "mang đi / không" (test bắt thiếu)
  - [ ] C7. Kho bí mật: mã hoá phía máy (scrypt / argon2id → AES-256-GCM) bằng cụm mật khẩu đồng bộ; cloud chỉ có bản mã + salt; máy mới nhập cụm mật khẩu để giải; đổi cụm mật khẩu = mã hoá lại; không ghi log / kết quả chạy nào có giá trị bí mật; mặc định **tắt** đồng bộ bí mật, bật phải xác nhận rủi ro
  - [ ] C8. UI Cài đặt → tab *Đồng bộ*: Đăng nhập Google, chọn phạm vi (4 công tắc), đồng bộ ngay, tự đồng bộ (khi mở app / sau khi lưu / mỗi N phút), trạng thái + lần cuối + lỗi; chấm trạng thái trên thanh dưới; màn mẫu `#demo-sync`; chương *Hướng dẫn* mới (`internal/guide/`)
  - [ ] C9. Backend **MCP**: provider dùng MCP server do người dùng khai (lệnh / URL) – ánh xạ 4 thao tác `List/Get/Put/Delete` sang tên tool của server (khai trong Cài đặt, có sẵn bộ ánh xạ cho server Drive phổ biến); lần đầu kết nối hỏi quyền; chung client với node *Gọi tool MCP* (31d); kết quả tool là dữ liệu, không làm theo như lệnh
  - [ ] C10. MCP của app: `sync_status` (chỉ đọc) cho AI; **không** có tool bật đồng bộ / đăng nhập / giải bí mật (AI không được tự đẩy dữ liệu ra ngoài); đồng bộ theo lịch (22) tuỳ chọn, đi qua chỗ hỏi quyền chung
  - Quyết định cần ghi `decisions.md` khi bắt đầu: phạm vi `drive.file`; bí mật mã hoá phía máy; xung đột luôn hỏi.
  - Chuẩn bị cho MCP: `sync_status`; guide ghi rõ AI không đụng được phần đăng nhập / bí mật.
  - Kiểm tra tay: đăng nhập Google từ máy sạch; đồng bộ lần đầu lên Drive rồi mở trên máy thứ hai (cả macOS ↔ Windows: đường dẫn ảnh mẫu); sửa cùng một kịch bản ở hai máy → hộp thoại xung đột; ngắt mạng giữa chừng; thu hồi quyền ở tài khoản Google → báo đăng nhập lại; máy mới nhập đúng / sai cụm mật khẩu để lấy bí mật.
  - Xong khi: hai máy dùng chung một bộ kịch bản + ảnh mẫu + cài đặt mang đi được qua Drive, mọi xung đột đều được hỏi, bí mật chỉ nằm trên cloud ở dạng bản mã.
