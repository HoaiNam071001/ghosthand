# 54. Đồng bộ kịch bản lên cloud (Google Drive, MCP)

- [x] **54. Đồng bộ cloud** *(người dùng yêu cầu 2026-10-28: đăng nhập Google rồi đồng bộ kịch bản + ảnh mẫu / tệp đi kèm + cài đặt + kho bí mật lên cloud, có thể qua MCP server khác; xung đột thì hỏi người dùng)*
  - **Đã có để dựa vào:** `store/revision.go` (revision kịch bản), `store/storagedirs.go` (thư mục kịch bản), `internal/secrets` (kho bí mật + keychain), `internal/ai` (mẫu gọi dịch vụ ngoài + key qua `{{secret.*}}`), **dùng chung client MCP** (`internal/mcpclient`, làm ở [bước 55](55-mcp-client-node-tuy-chinh.md)) với bước này, không viết hai lần.
  - **Cần chốt khi làm (mặc định đề xuất):** (1) backend đầu tiên = **Google Drive API trực tiếp** (OAuth loopback + PKCE, scope `drive.file` – app chỉ thấy file nó tạo, thư mục `Ghosthand` trong Drive); (2) backend **MCP** là đợt sau vì tên tool mỗi server Drive khác nhau → cần bảng ánh xạ; (3) bí mật **mã hoá phía máy** bằng cụm mật khẩu riêng, cloud chỉ giữ bản mã.
  - **Rủi ro:** đăng ký app Google (màn hình đồng ý OAuth, client ID đi kèm bản phát hành; `drive.file` không cần Google duyệt scope nhạy cảm); quên cụm mật khẩu = mất bí mật trên cloud (không khôi phục); hai máy sửa cùng lúc; ảnh mẫu nhiều → upload chậm (chỉ đẩy file đổi, so hash); token hết hạn giữa chừng.
