# 50. Góp ý khi dùng node: nút chọn file, bảng output, cửa sổ macOS, vẽ đường trên overlay…

- [x] **50. Góp ý khi dùng node 2026-10-25** *(người dùng yêu cầu 2026-10-25; làm theo nhóm A → E)*
  - **Chốt 2026-10-25:** gộp click ảnh / chữ / phần tử **chỉ trong modal thêm node** (model Go giữ 3 loại step); làm luôn node Cửa sổ / Ứng dụng cho macOS (= 26 W0c); thứ tự A → E.
  - **A. Lỗi giao diện + chẩn đoán**
    - [x] A1. UI tràn / chồng: node *Số & ngày* (3 nút Lấy số / Định dạng số / Ngày giờ ra khỏi khung), *Làm sạch chữ* (nút Hoa / thường, nhãn dài xuống 2 dòng) – `Segmented` tự xuống hàng hoặc cuộn, nhãn `Field` đủ rộng; rà các node có `Segmented` ≥ 4 lựa chọn – `Segmented` tự xuống hàng khi hẹp; bỏ khung `grid-cols-2` lồng trong node Làm sạch chữ / Số & ngày (nhãn 120 px đè lên ô)
    - [x] A2. Node *Thao tác phần tử* fail → log ra những gì Accessibility đã đọc được (app / cửa sổ, số phần tử, vai trò + tên + giá trị của các ứng viên gần giống, độ sâu cây) để biết vì sao không khớp; hiện trong chi tiết lỗi của bước + Lịch sử, chép được. Người dùng thấy phần tử có trong Accessibility Inspector mà app không tìm ra → kiểm tra luôn giới hạn độ sâu / số phần tử khi duyệt cây, thuộc tính khớp (`AXTitle` / `AXDescription` / `AXValue` / `AXIdentifier`), chuỗi con / không phân biệt hoa thường – `element.Dump` (tối đa 150 phần tử đọc được + đếm theo vai trò gốc AX) vào `detail` của lỗi phần tử; hộp *App đã đọc N phần tử* ở Nhật ký kèm gợi ý nguyên nhân (không có cửa sổ / chỉ có khung cửa sổ – Chrome chưa mở cây AX / cây bị cắt ở 20000) + nút chép
  - **B. Nút chọn file / thư mục (dùng chung)**
    - [x] B1. Component dùng chung `PathPicker` (ô nhập + nút *Chọn…* file / lưu file / thư mục; Go `PickFile` / `PickSavePath` bên cạnh `PickFolder` có sẵn ở `storagedirs.go`) + `VarTextInput` vẫn gõ được biến `{{…}}` – Go `App.PickPath(kind, title, current)` + `stepform/PathInput` (file / folder / save / any = hai nút)
    - [x] B2. Áp vào mọi ô đường dẫn: node Tệp / thư mục, Nén / giải nén (`ZipFields`), Chạy lệnh (thư mục làm việc), Lưu trang PDF (`SavePdfFields`), Chờ tải xong (`WaitDownloadFields`), Chụp màn hình lưu file, Đọc tài liệu… (rà bằng grep các trường đường dẫn trong `steptypes.go`) – Tệp / thư mục, Nén / giải nén, Chạy lệnh, Lưu PDF, Chờ tải, Chụp màn hình, Clipboard (ảnh), Đọc bảng
  - **C. Output dạng bảng**
    - [x] C1. Component hiển thị output: bảng *nhãn (tên + biến `{{nX.output.y}}`) – giá trị*, nút *Chép JSON* (từng node + tất cả); dùng ở tab Output của inspector, Lịch sử (đã có tab *Tất cả output* – bước 49 A4, đổi sang bảng) và nút chạy thử – `OutputTable` ở Lần chạy gần nhất, Nhật ký chi tiết, tab Tất cả output (bảng Nhãn · Biến · Giá trị + chép JSON)
  - **D. Nền tảng**
    - [x] D1. Mỗi loại node có danh sách hệ điều hành hỗ trợ (Go `steptypes.go` → TS); modal thêm node đánh dấu rõ node **không chạy được trên máy này** (làm mờ + nhãn *Chỉ macOS* / *Chỉ Windows*, vẫn xem được mô tả) thay vì để người dùng thêm rồi mới gặp lỗi lúc chạy – `model/platform.go` (`onlyOS`: browserTab / browserGo / browserNorm / savePdf / osShortcut = macOS), `App.Platform` + `StepOnlyOS`; modal thêm node hiện nhãn + cảnh báo ở khung mô tả, vẫn thêm được
    - [x] D2. Node Cửa sổ / Ứng dụng macOS = **26 W0c** (`window_darwin.go`: `CGWindowListCopyWindowInfo` + AX; xem file bước 26); bỏ cầu nối `window_other.go`, báo thiếu Screen Recording (tên cửa sổ trống) – `window_darwin.go` (cgo): CGWindowList + AX, tên cửa sổ lấy từ AX nên **không cần Screen Recording**; maximize = phủ vùng làm việc; chưa thử Focus / SetBounds / Close trên app thật (ghi ở checks)
  - **E. Tiện dùng**
    - [x] E1. Vẽ đường: mở overlay chọn đường như chọn điểm click – kéo một nét dài, app lấy mẫu theo chuột thành các điểm (giãn thưa theo khoảng cách tối thiểu, hàm thuần có test) rồi điền `points` – công cụ overlay `stroke` (`overlay/stroke.ts` Douglas–Peucker ≤ 80 điểm), nút *Vẽ trên màn hình…* trong form
    - [x] E2. Chọn loại node: gộp *Click theo ảnh / chữ / phần tử* thành một mục trong modal thêm node, chọn kiểu ngay trong form; lúc đổi kiểu dùng lại `ChangeTypePalette`; không đổi model – còn 1 mục *Click theo ảnh / chữ / phần tử* (chuyển cách tìm bằng ô *Tìm theo* có sẵn). Chờ ảnh / chữ / phần tử vẫn 3 mục – chưa gộp (người dùng chỉ nói click)
    - [x] E3. HTTP: ô *Dán lệnh curl* → phân tích (method, URL, header, body, `-u`, `--data*`, `-F` đơn giản…) tự điền các trường; hàm thuần `flow/curl.ts` + test – `flow/curl.ts` + `stepform/CurlImport` (query tách vào bảng, -u → Basic, -F ghi chú multipart)
    - [x] E4. Tiến trình: nút *Chọn…* mở hộp danh sách tiến trình đang chạy (tìm theo tên, hiện CPU / RAM, icon app nếu có) – dùng lại mẫu `AppPicker` / `WindowPicker` – `App.ListProcesses` (gom theo tên) + `ProcessPicker`; chọn xong đặt *Đúng*
    - [x] E5. Shortcut hệ điều hành: dễ hình dung – ví dụ + giải thích "Shortcut là gì", danh sách Shortcut có trong máy để chọn (nếu lấy được qua `shortcuts list`), mô tả đầu vào / đầu ra – khung giải thích + ví dụ ở đầu form; báo khi máy chưa có Shortcut nào (danh sách chọn đã có từ trước)
  - Chuẩn bị cho MCP (31): D1 cho MCP biết node nào chạy được ở máy này (mô tả tool); A2 đưa chi tiết lỗi có cấu trúc (`StepError`); không đổi tool khác

  - Xong khi: không node nào tràn khung; mọi ô đường dẫn có nút Chọn; output xem dạng bảng + chép JSON; modal thêm node báo rõ node không hỗ trợ máy này; Cửa sổ / Ứng dụng chạy trên Mac; vẽ đường chọn trên màn hình; dán curl tự điền; chọn tiến trình bằng hộp; Thao tác phần tử fail cho thấy cây Accessibility đã đọc.
