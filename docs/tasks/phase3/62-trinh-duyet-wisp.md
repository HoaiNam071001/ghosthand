# 62. Wisp làm trình duyệt của node web

- [x] **62. Wisp làm trình duyệt của node web** *(người dùng yêu cầu 2026-11-15 – bước 02 của plan Wisp ở `../flash-app/docs/plan/02-ghosthand-backend-wisp.md`)* – node web hiện có (`webWait`, `webClick`, `webType`, `webRead`, `webScroll`, `webKey`, node Mở với *Chrome của app*) chạy trên trình duyệt Wisp qua cổng Ghosthand của Wisp (WebSocket `127.0.0.1` + token, sự kiện thật `sendInputEvent`), không sửa kịch bản.
  - Người dùng chốt (2026-11-15): chọn ở **Cài đặt chung** – *Trình duyệt cho node web*: Tự động (Wisp nếu đang mở + cổng bật, không thì Chrome của app – mặc định) / Chrome của app / Wisp; trên Wisp mọi thao tác **luôn qua cổng** (như chạy nền – không chiếm chuột, không đưa cửa sổ lên); đã chọn Wisp mà Wisp chưa mở → **tự mở Wisp rồi chờ** `ghosthand.json` (~20 s).
  - [x] W1. `internal/wisp/`: đọc `ghosthand.json` (thư mục dữ liệu Wisp: `WISP_USER_DATA` hoặc `~/Library/Application Support/Wisp` / `%APPDATA%\Wisp`, pid còn sống, `api` 1), client WebSocket (gorilla, một kết nối, lệnh có id, sự kiện đẩy, mã đóng 4000 = người dùng ngắt), mở app Wisp + chờ.
  - [x] W2. `wisp.Browser` cài `web.Browser`: `Find` → `find` (`all` cho `Occurrence`, `scope`, `covered`, `hidden`, đọc `read`), `BgClick` → `click {ref, offset}`, `BgWheel` → `scroll`, `BgType` → `type` không đích, `Focused` → `focused {ref}`, `Keys` → `keys`, `PageOutline` → `outline`, `Mark` / `Settle` → sự kiện `navigate` / `popup` + `settle`, hộp thoại JS → sự kiện `dialog` + lệnh `dialog`. Phần đổi dữ liệu thuần có test.
  - [x] W3. Engine: trình duyệt báo "thao tác qua cổng" (`web.Native`) → node web chạy như *chạy nền* dù kịch bản không bật.
  - [x] W4. Cài đặt → tab *Trình duyệt*: Tự động / Chrome của app / Wisp + trạng thái Wisp (chưa mở / cổng tắt / sẵn sàng). `Deps.Browser` chọn theo cài đặt.
  - [x] W5. MCP: `probe_page`, `read_web_outline`, `suggest_selector`, `describe_screen` dùng được với tab Wisp; primer / `get_step_types topic=web` ghi ngắn "có Wisp thì dùng Wisp" (giữ `budget_test.go`).
  - [x] W6. Hướng dẫn: chương web (`internal/guide/`) thêm phần Wisp.
  - *Làm (2026-11-15):* cổng Wisp thêm `find` `scope` / `brief` / `covered` / `hidden`, `focused {ref}`, `type` không đích, sự kiện `dialog {closed}` (vẫn api 1). Sắp bấm (`Query.Scroll`): cuộn tới (lệnh `scroll` tới ref) + đọc lại sau 60 ms – khung đổi → `Moving`, ngoài khung nhìn / bị che → chưa thấy (nút trượt vào ở mẫu iframe). `BgClick(x, y)` → `click {ref, offset}` của lần Find gần nhất; `Mark.Doc` = số lần `navigate` của tab. Sân thử *Mẫu thử* phục vụ qua http `127.0.0.1` khi dùng Wisp (cổng Wisp không mở `file://`). MCP: `read_web_outline` + chụp tab + *Thử tìm* theo Cài đặt; `probe_page` / *Chọn phần tử trên trang* vẫn Chrome của app (chọn trên Wisp = bước 06 của Wisp). Thử thật: `GHOSTHAND_REAL=1 GHOSTHAND_BROWSER=wisp` 11/11 mẫu web sân thử qua trên Wisp dev; `WISP_REAL=1` `TestRealWisp` qua.
  - [ ] Settle trên Wisp chờ DOM yên 500 ms (lệnh `settle` = `waitLoad idle`) – chậm hơn Chrome của app (100 ms); thêm `quietMs` ở cổng Wisp nếu thấy chậm.
